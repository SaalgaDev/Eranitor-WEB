# Marca Eranitor

Versões em SVG da logo (`assets/images/logo.png`).

- `eranitor-logo-*.svg`: nome com o capelo
- `eranitor-wordmark-*.svg`: só o nome
- `eranitor-icon-*.svg`: só o capelo
- `eranitor-app-icon.svg`: ícone quadrado usado como favicon

Sufixo `-navy` (#101A2B) para fundo claro e `-cream` (#FFF5E8) para fundo escuro.

No site, use `<app-logo kind="full">`, `kind="wordmark"` ou `kind="icon"`. A cor segue o `color` do elemento pai.
